# 门店陈列合规检查 Agent 说明（第 2–5 部分）

## 2. 使用说明

本 Agent 面向服装连锁总部督导，用于上传门店陈列照片并对照总部统一标准自动巡检。

**支持的输入**

| 类型 | 是否支持 | 说明 |
|------|----------|------|
| 门店陈列照片 | 支持 | JPG / PNG / WebP / GIF，单次最多 8 张，单张不超过 12 MB |
| 门店编号、门店名称、拍摄备注 | 支持 | 文字，选填，仅用于归档，不参与规则判定 |
| PDF、Excel、Word | 不支持 | 不解析文档、表格或长文本 SOP |
| 纯文字描述店况 | 不支持 | 不以口述代替照片，避免无图推测 |

使用方式：打开页面后拖拽或选择照片，填写门店信息（可选），点击「开始检查」。也可调用 `POST /api/inspect`（`multipart/form-data`，字段 `files`、`store_id`、`store_name`、`note`）。

不支持的情况会明确拒绝或标记「无法判断」，例如空文件、非图片格式、过暗/模糊导致无法检视。

---

## 3. 规则使用说明

Agent **不允许只靠大模型常识自由发挥**。题目给出的检查规则被写成代码中的唯一标准源 `display_inspect/rules.py`，同时用于：提示词、后处理护栏、前端「检查标准」页。模型只能对照这些条文判断照片里**看得见的证据**。

**规则如何进入检查过程**

1. **规则入库**：七类标准（照片有效性、挂装、叠装、模特、鞋包配件、价签、清洁与安全）及严重度定义固化在 `RULES` / `SEVERITY_GUIDE` 中，与题目表格一致。
2. **本地预检**：用亮度、边缘强度检测过暗、过曝、模糊。全局不可用时**不调用视觉模型**，直接按「照片有效性」规则把其余类别标为「无法判断」，禁止推测整店。
3. **视觉对照**：照片可用时，把规则全文和图片一并交给 DeepSeek 视觉模型；系统提示要求逐条对照，不得编造未见区域。
4. **规则护栏（后处理）**：
   - 七个类别必须都有结论，缺类补「无法判断」；
   - 「对应检查标准」**强制改写为总部原文**，不用模型改写稿；
   - 价签文字看不清时，问题描述必须出现「内容无法判断」；
   - 商品落地、消防/疏散占用、设施松脱倾斜等，严重度校准为「高」；
   - 可见项有明确违规则总评为「不合规」；仅有「无法判断」而无确认违规时，总评不得写成整店「合规」。

因此：判定依据是题目规则 + 照片可见证据，而不是模型对「一家服装店应该什么样」的常识。

## 4. 输出格式说明

每次检查输出一份结构化报告（页面卡片 / JSON 相同字段）。

**总评**

| 字段 | 含义 |
|------|------|
| 是否合规（overall） | `合规` / `不合规` / `无法判断` |
| 结论摘要（summary） | 一句话说明；不确定时必须出现「无法判断」 |
| 照片质量（photo_quality） | 分辨率、亮度、是否过暗/模糊等预检结果 |

**每一类检查项（findings，固定 7 条）**

| 字段 | 含义 |
|------|------|
| 类别（category） | 照片有效性 / 挂装 / 叠装 / 模特 / 鞋包配件 / 价签 / 清洁与安全 |
| 是否合规（compliant） | `合规` / `不合规` / `无法判断` |
| 具体问题（issue） | 看见了什么问题；看不清则写明原因，并使用「无法判断」 |
| 对应检查标准（standard） | 总部规则原文，不改写 |
| 问题所在区域（region） | 画面位置，如「左侧挂杆中段」；无法定位则「无法判断」 |
| 严重程度（severity） | `高` / `中` / `低` / `无法判断` |
| 整改建议（suggestion） | 可执行动作；证据不足时要求补拍，不给猜测性整改 |

严重度口径与题目一致：高＝安全、疏散、设施坠落、商品落地；中＝影响可售性或整洁；低＝对齐、间距、色序等视觉问题。

## 5. 自测样例

以下为候选人实际跑通的两次检查（同一套 Agent）。

### 样例 A：过暗照片（验证「无法判断」、不推测整店）

- **输入**：几乎全黑的 JPEG（`too_dark.jpg`，960×720），门店名称「过暗测试店」
- **预检**：亮度 5.0，判定过暗且模糊，未调用视觉模型猜店况
- **测试时间**：2026-09-15 16:05:21
- **单号**：`dcdd9168133a`

**输出摘要**

| 字段 | 结果 |
|------|------|
| 是否合规 | 无法判断 |
| 结论摘要 | 照片模糊或过暗，相关项无法判断，不能推测整店情况。 |

| 类别 | 是否合规 | 具体问题 | 对应检查标准 | 区域 | 严重程度 | 整改建议 |
|------|----------|----------|--------------|------|----------|----------|
| 照片有效性 | 不合规 | 照片过暗、模糊，不具备可靠巡检条件 | 照片应清晰、曝光正常、陈列主体完整入镜、无大面积遮挡。模糊、过暗、遮挡、局部未入镜时，相关项必须输出「无法判断」，不能推测整店情况。 | 全图 | 中 | 请在光线充足处重新拍摄清晰、完整、无遮挡的陈列照片。 |
| 挂装 | 无法判断 | 照片过暗、模糊，相关项无法判断，不能推测整店情况 | 同组衣架方向、材质和颜色一致；间距均匀；衣物自然垂直；按品类与连续色序分组；不得大面积空挂。 | 无法判断 | 无法判断 | 请补拍该区域清晰、完整、无遮挡的照片后再检查，勿凭推测整改。 |

| 价签 | 无法判断 | 同上 | 每个陈列组有价签；价签直立、正向、无遮挡；看不清文字时仅能判断「内容无法判断」。 | 无法判断 | 无法判断 | 同上 |

该样例证明：输入无效照片时，Agent 会按规则停检，而不会用常识编造整店陈列结论。
